# 2BHK House – Blender Project

A 3D model of a 2BHK house with a garage and car, made in Blender.

## Features
- Living room with sofa and coffee table
- Kitchen
- 2 bedrooms
- Garage with a car

## Requirements
- Blender 5.2 LTS

## How to Open
1. Download `2BHK.blend`
2. Open Blender
3. Go to File > Open and select the file

## Render
Press F12 to render an image.
